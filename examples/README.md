# KiCad Copilot examples

These are real projects generated and iterated through KiCad Copilot. Extract an archive and open its `.kicad_pro` file with KiCad 9 or 10.

## Projects

- [`atmega328p_dev.zip`](atmega328p_dev.zip): hierarchical ATmega328P development board schematic.
- [`geiger_hv.zip`](geiger_hv.zip): multi-sheet Geiger counter power, high-voltage, detector, control, and UI design.
- [`rp2350_debug.zip`](rp2350_debug.zip): hierarchical RP2350 development board with PCB and placement DSL.

Each directory contains its project-local symbol and footprint libraries. The RP2350 example also includes the compact WRL models referenced by its PCB so that KiCad's 3D Viewer works without the much larger STEP source files.

Generated reports, editor state, checkpoints, history, backups, and temporary previews are intentionally omitted.
